# Neon Portfolio — Personal Website

A responsive, dark-futuristic personal portfolio built with plain HTML, CSS, and JavaScript. No framework, build step, or package installation is required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the **Live Server** extension in VS Code.

## Customize it

The site currently uses sample content for **Alex Morgan**. Replace these details with your own:

- **Name and intro:** Update the page title, hero heading, and introductory paragraphs in `index.html`.
- **Location and stats:** Update the hero metadata and stats section.
- **Projects:** Replace the NOVA, Kinetic, and MONO sample projects with your real work, descriptions, and links.
- **Skills:** Edit the toolkit list to match your experience.
- **Contact:** Replace `hello@example.com` in the email link with your email address.
- **Social links:** Replace the example GitHub and LinkedIn URLs in the footer.
- **Colors and typography:** Adjust the CSS variables at the top of `style.css`.

## Features

- Responsive desktop and mobile layouts
- Neon cyan and violet visual system, orbital artwork, and subtle glow effects
- Mobile navigation with accessible expanded state
- Scroll-triggered reveal animations
- Reduced-motion preference support
- Project cards, skills section, and contact call to action
- No dependencies or build tooling

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for the deployment to finish. GitHub will show the published URL in the Pages section.
